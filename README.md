# 🏏 IPL Analysis Dashboard (2008–2025)

An interactive **IPL Data Analysis Dashboard** developed using **Microsoft Power BI** to analyze IPL seasons, team performance, player statistics, match outcomes, and key tournament KPIs.

This project was developed as **Project 3 of my Data Analytics Internship**.

---

## 📊 Project Overview

The objective of this project was to transform raw IPL match and player data into an interactive dashboard that provides meaningful insights into:

- Team performance
- Player performance
- Season-wise statistics
- Match results
- Batting and bowling achievements
- Points table
- Venue analysis

The dashboard allows users to select a specific IPL season and dynamically explore the corresponding statistics.

---

## 🎯 Key Features

### 🏆 Season Overview
- Season Winner
- Runner-up
- Total Matches
- Total Teams
- Total Venues

### 🟠 Orange Cap Analysis
- Top run scorer
- Total runs
- Player's team

### 🟣 Purple Cap Analysis
- Top wicket taker
- Total wickets
- Player's team

### 💥 Batting Analysis
- Total 4s
- Total 6s
- Top players based on boundaries

### 📋 Team Performance
- Points table
- Matches played
- Wins
- Losses
- Ties
- Net Run Rate
- Total points

### 📍 Venue Analysis
- Number of venues
- Venue-wise match information

### 🔎 Interactive Filtering
Users can select different IPL seasons to dynamically update the dashboard and analyze season-specific performance.
